# AVENTURE GAME

## Historia
Eres un aventurero atrapado en un laberinto mágico. En cada turno debes elegir una ruta:
- 📦Abrir un cofre
- 👹Luchar contra un monstruo
- 🏃Huir
- ❤️Descansar
- 🚪Salir del juego

Tu objetivo es sobrevivir y conseguir el máximo de oro posible.
